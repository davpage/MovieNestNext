# 🎬 MovieNest

**MovieNest** is a web application that allows users to search for, watch, and save movies to their favorites list.

## 📌 Features

- 🔍 Search movies by name
- ❤️ List of top-rated movies
- 🧑‍💻 Download option available
- 💻 Contact and feedback form

## ⚙️ Technologies

- **Frontend:** React / Next.js
- **Styling:** Tailwind CSS / Sass
- **Backend:** Node.js / Express.js

## 🚀 Access [MovieNest](https://movienest.live/)
